- [Typescript](https://www.typescriptlang.org/)

- [shadcn/ui](https://ui.shadcn.com/)
- [Vite](https://vitejs.dev/)
- [Cloudflare](https://www.cloudflare.com/) / [wrangler](https://developers.cloudflare.com/workers/wrangler/) for hosting
